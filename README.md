# David Akilo — Portfolio

Personal portfolio site for David Akilo, an AI systems engineer building Claude
Code automations for D2C ecommerce brands.

Single-file static site: `index.html` with inline CSS/JS, plus `assets/`.

## Local preview

```bash
npx serve .
```

or open `index.html` directly in a browser.

## Contact form

Submissions go through [Web3Forms](https://web3forms.com) — no backend
required. The access key in the form is a public-facing key by design (same
model as a reCAPTCHA site key), not a secret credential.

## Deployment

Static site, zero build step. Deploy target: Vercel (import this repo on
vercel.com, no configuration needed).
